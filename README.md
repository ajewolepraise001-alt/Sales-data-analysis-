# 📊 Sales Data Analysis

## Project Overview

This is my first Data Analysis portfolio project. I analyzed a sales dataset to understand sales performance across different products, salespeople, and locations.

## 🎯 Project Objectives

The main objectives were to:

- Calculate total sales
- Calculate average sales
- Identify the highest transaction
- Analyze sales by location
- Analyze sales by salesperson
- Identify high-value transactions
- Summarize the data using Pivot Tables
- Generate useful business insights

## 🛠️ Tools Used

- WPS Spreadsheet
- Excel
- Pivot Tables
- Spreadsheet formulas
- GitHub

## 📋 Analysis Performed

### Sales Calculations

I used spreadsheet formulas to calculate:

- Total Sales
- Average Sales
- Maximum Transaction
- Minimum Transaction
- Number of Transactions

### Conditional Analysis

I used the IF function to classify transactions into:

- HIGH
- LOW

### Location Analysis

I analyzed transactions by location and used COUNTIF/SUMIF techniques to understand location performance.

### Pivot Table Analysis

I created Pivot Tables to summarize the dataset and compare sales performance across different categories.

## 🔍 Key Findings

- The highest individual transaction was ₦900,000.
- Lagos had 5 transactions in the dataset.
- Pivot Tables were used to summarize and compare sales performance.
- The analysis helped identify differences in sales performance across locations and salespeople.

## 💡 Business Insights

The analysis demonstrates how spreadsheet-based data analysis can help businesses understand:

- Where sales are coming from
- Which transactions have the highest value
- Which locations perform better
- How salespeople contribute to overall sales
